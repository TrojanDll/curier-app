Планируется приложение формата saas (приложение как услуга). Делать реализацию оплаты самого приложения не нужно, никаких защит для этого создавать не надо. Это будет приложение для курьеров для частных предпринимателей. Частный предприниматель, например владелец сети магазинов быстрого питания имеет у себя администраторское приложение. Через него он будет назначать задачу курьерам. Сам заказ администратор будет получать другими каналами, в реализации приложения это учитываться не должно. После получения заказа администратор создает новую задачу в администраторском приложении, выбирает курьера из списка доступных нанятых курьеров и поручает ему эту задачу. Внимание!!! Делать администраторское приложение НЕ нужно! Это не входит в твои задачи! Я привёл информацию для понимания контекста! Не делай администраторское приложение! Твоя задача выполнить курьерское приложение. Курьерское приложение будет представлять собой несколько вкладок. Первая вкладка профиль. В профиле курьер должен зарегистрироваться или войти в аккаунт, введя логин и пароль. В профиле чисто для галочки должны быть какие то пользовательские настройки, которые должны сохраняться и подтягиваться с сервера при входе в аккаунт на другом устройстве или при переустановке приложения. Примером пользовательских настроек может быть дата рождения, телефонный номер, email и др., много добавлять не нужно. Следующая вкладка будет история. В этой вкладке будет просто список всех  выполненных заказов с информацией о заказе за определенный период. Следующая страница - окно заказов. Сюда будут приходить задачи от администратора. Тут видны только активные задачи. Курьер может просмотреть описание задачи, адрес доставки и другую необходимую информацию о заказе. Во время выполнения задачи курьер должен отмечать статусы: "забрал заказ", "Возле дома клиента", "Передал заказ", "Вернулся на предприятие". Предусмотреть, чтобы администратор своевременно мог видеть изменение статусов каждого курьера (просто подготовить api курьерского приложения, реализовывать администраторское приложение не нужно!).
