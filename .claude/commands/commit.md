## Контекст

- Текущий статус: !`git status`
- Diff изменений: !`git diff HEAD`
- Последние коммиты: !`git log --oneline -5`

## Задача

Проанализируй изменения и создай один git-коммит.

### Формат сообщения коммита

```
тип: краткое описание в несколько слов
```

Типы: `feat`, `fix`, `refactor`, `delete`

- `feat` — новый функционал
- `fix` — исправление бага
- `refactor` — рефакторинг без изменения поведения
- `delete` — удаление кода/файлов

### Требования

- Описание максимально краткое: 3–6 слов
- Описание на английском языке
- Без упоминания себя или соавторов
- Без строки `Co-Authored-By`

### Действия

1. Добавь все изменённые файлы: `git add -A`
2. Создай коммит с сообщением в нужном формате

Выполни оба действия одним сообщением, без лишнего текста.
