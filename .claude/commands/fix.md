# /fix — Выполнить задачу из MD-файла

Ты получил задачу из файла. Выполни её, следуя всем правилам проекта.

## Входные данные

Путь к файлу задачи: $ARGUMENTS

## Алгоритм выполнения

### 1. Прочитай задачу
- Прочитай файл задачи по указанному пути.
- Проверь, есть ли связанные скриншоты. Номер задачи берётся из имени файла (например, `6.md` → номер `6`). Связанные картинки могут называться: `6.png`, `6.jpg`, `6_1.png`, `6_2.png` и т.д. — они лежат в той же папке, что и файл задачи. Если картинки найдены — прочитай их (Read tool умеет показывать изображения).
- Разберись, что нужно сделать. Если задача неясна — задай пользователю уточняющие вопросы.

### 2. Изучи контекст
- Прочитай `docs/INDEX.md`.
- Если задача касается конкретной секции/компонента и для неё есть doc — прочитай его.
- Найди связанные исходные файлы через Glob/Grep.

### 3. Выполни задачу
- Внеси правки в код, следуя конвенциям проекта.
- **НЕ запускай билд/dev команды** — пользователь делает это сам.

### 4. Отчитайся
- Кратко сообщи, что было изменено и в каких файлах.
- Если в процессе работы обнаружилась новая информация о проекте, которой нет в docs/ — создай или обнови соответствующий doc и обнови `docs/INDEX.md`.
- Обязательно укажи в конце: `Docs updated: YES (docs/X.md)` или `Docs updated: NO — причина`.
